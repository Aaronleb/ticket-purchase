大麦抢票 Windows 免安装版（仅 PC 抢票）
=========================================

一、运行条件
------------
1. Windows 10/11 64 位。
2. 无需安装 Python、Chrome、ChromeDriver 或任何依赖，解压即用。
3. 抢票、扫码登录时需要能访问大麦网。

二、使用步骤
------------
1. 把整个文件夹解压到有写入权限的位置，例如 D:\大麦抢票\。
   不要直接在压缩包里运行，也不要放到 C:\Program Files 下。
2. 双击“启动抢票.bat”。浏览器会自动打开 http://127.0.0.1:8765。
3. 在控制台填写演出链接、城市、日期、票价和观演人，保存配置。本包只提供 PC 入口，不会显示安卓页签。
4. 点击“运行环境自检”。内置 Chrome 与 ChromeDriver 会自动匹配，不需要联网下载驱动。
5. 没有登录态时点击“打开扫码登录”，用大麦 App 扫码；完成后回到页面点“我已完成登录”。
6. 点击“开始 PC 抢票”，需要停止时点“停止任务”。

三、数据位置
------------
- PC 配置：damai\config.json
- 登录 Cookie：damai\damai_cookies.pkl（含登录态，请不要外传）
- 内置浏览器：browser\chrome-win64\
- 内置驱动：browser\chromedriver-win64\
- 控制台端口固定为 8765，只监听本机 127.0.0.1

四、常见问题
------------
1. 提示“无法启动 Web 服务：Address already in use”
   说明 8765 端口被占用，关闭之前的抢票窗口或重启电脑后再试。
2. 环境自检提示浏览器版本不匹配
   本包内置的 Chrome 与 ChromeDriver 是同一版本。如手动替换过 browser 目录，
   请保证 chrome-win64 和 chromedriver-win64 主版本号一致，并同步修改 browser\VERSION。
3. Windows 弹出安全提示
   本包未做代码签名，选择“仍要运行”即可。Python 来自 python.org 官方发行版，
   Chrome 来自 Chrome for Testing 官方构建。
4. 杀毒软件误报
   抢票脚本会启动浏览器和子进程，属于正常行为；可将整个目录加入信任列表。

五、说明
--------
本包只包含 PC 抢票所需组件，不包含安卓 Appium / adb / Node.js，安卓入口不可用。
配置和 Cookie 都保存在本目录内，删除目录即可完成卸载。
