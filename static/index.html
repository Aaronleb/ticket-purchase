QUICK GUIDE

使用说明

  1. 1

    先检查运行环境

    点击“运行环境自检”，确认 Python、Selenium、Chrome 和 ChromeDriver 均通过。如果失败，可在实时日志中查看具体原因。

  2. 2

    完成大麦扫码登录

    点击“打开扫码登录”，在新打开的 Chrome 窗口中扫码。完成后回到本页面，点击“我已完成登录”，登录态会保存在本机。

  3. 3

    填写并保存演出配置

    粘贴大麦演出详情页链接，填写城市、日期、票价和观演人。多个日期或票价候选项用逗号分隔；观演人姓名需与大麦账号中的姓名一致。

  4. 4

    启动、停止并确认订单

    点击“开始抢票”后，页面会显示进程状态和实时日志。需要中止时点击“停止任务”。进程结束不代表购票成功，请在大麦订单中确认是否生成待支付订单，并及时完成支付。

关于自动提交订单

开启后，脚本到达订单确认页时会尝试自动选择观演人并提交。首次使用建议保持关闭，确认场次、票价和观演人无误后再开启。

安卓端使用步骤

1. 准备 Appium 与手机

安装 Appium、UiAutomator2 驱动和 Android SDK Platform-Tools，连接已开启 USB 调试的手机或模拟器。在终端运行 appium --address 127.0.0.1 --port 4723，用 adb devices 确认设备名。

2. 登录并打开详情页

在手机的官方大麦 App 中提前登录，添加观演人并打开目标演出详情页，保持手机亮屏。安卓端不使用 PC 扫码 Cookie。

3. 保存配置并检查环境

填写 Appium 地址、设备名、Android 版本、城市、票档序号和观演人。票档序号从 0 开始。保存后点击“检查安卓环境”，全部通过再启动。

4. 启动并确认订单

关闭自动提交时，脚本会停在订单确认页；开启后会尝试点击提交。两种情况下都必须在大麦 App 的订单记录中确认结果。

常见问题与排查

点击扫码登录后没有打开 Chrome

先运行环境自检并查看实时日志。若提示缺少 Selenium 或 ChromeDriver，请修复依赖后重试；登录进程异常退出时，页面会显示“需要处理”。

找不到日期、票价或观演人

检查输入是否与大麦页面一致，可为日期和票价填写多个候选格式。观演人需提前添加到大麦账号，并确保姓名完全一致。

日志显示流程结束，但没有订单

点击按钮或进程退出都不等于订单创建成功。请检查日志中的异常、页面跳转和观演人选择情况，最终以大麦订单记录为准。
