# 大麦安卓独立窗口实施计划

对应设计：`2026-11-07-android-webview-design.md`。

## 1. 拆分控制台运行与图形界面

- 将 HTTP 服务运行和统一资源清理整理为可测试的小函数。
- 默认在 macOS 主线程启动 pywebview，HTTP 服务在后台线程运行。
- 保留 `--no-browser` 作为兼容的无窗口参数，必要时增加含义更清晰的 `--no-window` 别名。
- 保证窗口关闭、终止信号和异常路径只执行一次完整清理。

## 2. 加入并固定桌面依赖

- 在 `requirements-build.txt` 固定 pywebview 版本。
- 通过实际 PyInstaller 构建确认 PyObjC、WKWebView 和 Cocoa 绑定被收集。
- 更新第三方许可说明，不改变最终用户免安装依赖的交付方式。

## 3. 测试生命周期

- 使用模拟 WebView 和服务器覆盖默认窗口、无窗口模式、关闭清理和异常清理。
- 保留现有 Appium、worker、配置和控制台测试。
- 避免单元测试创建真实窗口或访问真实用户目录。

## 4. 更新文档和交付验证

- 更新 README 与 DMG 首次打开说明，改为独立窗口和关闭即退出。
- 运行完整 unittest、原项目安卓 pytest 和静态语法检查。
- 重新构建 `dist/DamaiAndroid-arm64.dmg`。
- 从 DMG 完成无窗口端到端验证，再启动真实应用窗口检查内容与退出行为。
- 删除不再需要的构建中间目录，记录新 DMG 大小、校验值及未完成的真机验收。
