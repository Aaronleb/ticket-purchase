# 内场票档 OCR 实施计划

1. 确认 RapidOCR 可用版本，添加固定依赖并检查模型和 ONNX 运行时的打包要求。
2. 新增票档准备模块：读取一次卡片位置和截图 OCR，解析区域、价格并缓存内场候选的降序列表。
3. 在配置和 Web 页面中用票档区域、价格策略替代序号输入，保留旧配置读取兼容。
4. 在安卓主流程中复用缓存候选，只做轻量库存检查、直接点击和合计价格核对，失败则停止后续购买与提交。
5. 添加解析、筛选、缓存顺序、缺货降级和失败保护测试，运行完整项目测试。
6. 在真机上验证准备阶段只识别一次，再在自动提交关闭时验证缓存选票，不提交订单。
7. 更新 README，重建 DMG 并验证内嵌 OCR 模型、独立窗口和退出行为。
