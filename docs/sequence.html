标准模式 vs 极速模式

差别不在「点得快」，而在开售瞬间要不要读页面。标准模式每一步都要用 dump（1.5 秒一次）或 OCR 确认页面状态；极速模式把页面判断压成 0.1 秒的 Activity 查询，点击位置全部提前算好。

预热 / 说明 关键动作 校验 / 记录 右侧数字为实测累计耗时

① 标准模式（fast_mode = false）

≈ 9.1 s 到达确认页

每一步都要问「现在到哪一步了」——贵在读取，不在点击。实测整轮 9.1 s。

② 极速模式（fast_mode = true）

≈ 1.9 s 提交发出

票档与观演人由你在 App 里预选好，脚本只负责三次点击。实测提交发出 ≈ 1.9 s。

③ 极速模式的兜底分支

≈ 6.9 s 退化为标准链路

「确定」点了不生效（票档没预选、底部还是 ¥0）时，自动退回 OCR 现场补一次，不会卡死。
